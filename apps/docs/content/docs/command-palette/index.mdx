---
title: Command Palette
description: The global overlay for tab search and quick actions.
---

Press `⌥K` (or `Alt+K` on Windows/Linux) to open the command palette from any tab. It provides instant access to:

- **Tab search** — Find and switch to any open tab by title or URL
- **Quick actions** — Close tabs, move to spaces, pin favorites
- **AI commands** — Tidy tabs, group by topic, rename titles
- **History** — Recently closed tabs, instantly restorable

The command palette is injected as a content script overlay, so it works on any page without leaving your current context.
