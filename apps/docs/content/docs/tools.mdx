The agent comes equipped with a comprehensive suite of tools to interact with your browser. When you ask the agent to perform a task, it autonomously selects and uses these tools to get the job done.

<Callout type="warn" title="Security & Approvals">
  For sensitive actions (like `executeOnPage` or modifying memory), the agent will ask for your explicit approval before running the tool. You can choose to allow it once, or "Always allow on this site" to streamline your workflow.
</Callout>

## Browsing & Interaction

The agent can navigate the web and interact with elements just like a human user.

| Tool | Description | Example Usage |
|------|-------------|---------------|
| `navigate` | Navigate the active tab to a URL. | `navigate("https://github.com")` |
| `snapshot` | Capture a structural snapshot of the DOM. | `snapshot()` |
| `readPage` | Extract text, links, and metadata from the page. | `readPage()` |
| `screenshot` | Capture a visual screenshot of the viewport. | `screenshot()` |
| `scrollPage` | Scroll up, down, or to a specific position. | `scrollPage({ direction: "down" })` |
| `clickElement` | Click a specific element on the page. | `clickElement("@e42")` |
| `typeInElement` | Type text into an input field or textarea. | `typeInElement("@e7", "Hello world")` |

## Tab Management

The agent can see your open tabs and help you manage them.

| Tool | Description |
|------|-------------|
| `listTabs` | See all open tabs across your spaces. |
| `selectTab` | Switch focus to a specific tab. |

## Code Execution

The agent can run JavaScript to perform complex extractions or manipulate the page.

| Tool | Description | Security |
|------|-------------|----------|
| `executeCode` | Run JavaScript in an isolated worker to process data. | Safe (Isolated) |
| `executeOnPage` | Run JavaScript directly in the active page's context. | **Requires Approval** |

## Task Planning

For complex, multi-step operations, the agent can create a structured plan to keep track of its progress.

| Tool | Description |
|------|-------------|
| `todoWrite` | Create or update a persistent task list pinned in the side panel. |

## Memory

The agent has a persistent memory system to remember context across conversations. See [Memory](/docs/memory) for more details.

| Tool | Description |
|------|-------------|
| `saveMemory` | Store a new piece of information. |
| `recallMemory` | Search previously saved memories. |
| `updateMemory` | Update an existing memory entry. |
| `deleteMemory` | Remove a memory entry. |
