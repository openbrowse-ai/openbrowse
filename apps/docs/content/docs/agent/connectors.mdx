Connectors let the agent interact with external services using the Model Context Protocol (MCP). Each connector provides tools that the agent can use during conversations.

## Available Connectors

Browse all connectors on the [Connectors page](/connectors).

## How It Works

1. Go to **Settings → Connectors**
2. Browse available connectors by category
3. Click a connector and authenticate (OAuth, API key, or token)
4. The connector's tools become available to the agent

## Categories

- **Developer Tools** — GitHub, Linear, Sentry, Vercel
- **Productivity** — Notion, Slack
- **Databases** — Supabase
- **Analytics** — Stripe

## Adding Custom Connectors

Any MCP-compatible server can be added as a custom connector. Provide the server URL and authentication details in Settings.
