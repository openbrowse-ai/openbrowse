title: Memory
description: The agent's persistent memory system for context across conversations.
---

The agent can save, recall, update, and delete memories that persist across conversations. This allows it to remember your preferences, project context, and prior interactions.

## How It Works

Memories are stored locally in your browser's extension storage. They are never sent to external servers.

## Operations

- **Save** — Store a new piece of information with a key and content
- **Recall** — Search memories by query (semantic or keyword)
- **Update** — Modify an existing memory
- **Delete** — Remove a memory that's no longer relevant

## Use Cases

- Remember project names and URLs you work with frequently
- Store preferences for how you like tasks done
- Keep track of ongoing work across sessions
