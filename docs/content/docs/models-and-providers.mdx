title: Models & Providers
description: Configure AI models — run locally or bring your own API key.
---

OpenBrowse works with any AI provider. Run entirely local with no API key, or connect to cloud providers.

## Local Models (No API Key)

| Provider | Setup |
|----------|-------|
| Chrome Built-in AI (Gemini Nano) | No setup needed — works out of the box |
| WebLLM (Llama, Phi, etc.) | Download a model in Settings → Models |

## Cloud Providers (BYOK)

| Provider | Setup |
|----------|-------|
| OpenAI | API key |
| Anthropic | API key |
| Google Gemini | API key |
| OpenAI-Compatible (Groq, Together, etc.) | API key + base URL |

## Configuration

1. Go to **Settings → Models**
2. Select a provider
3. Enter your API key (for cloud providers)
4. Choose a default model

Your API keys are stored locally in extension storage and never sent to OpenBrowse servers.
