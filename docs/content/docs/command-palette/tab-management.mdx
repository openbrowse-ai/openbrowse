## Spaces

Spaces are window-based tab groups. Each Chrome window maps to a space with:

- A custom name
- A color theme applied to the window
- Independent tab organization

## Favorites

Pin frequently-used tabs as favorites. Favorites persist across sessions and are accessible from the command palette and home page.

## History

Recently closed tabs are tracked and instantly restorable from the command palette. Search by title or URL to find what you closed.

## AI Tidy

AI Tidy uses your configured model to semantically group tabs by topic and clean up tab titles. Select tabs in the command palette and run the tidy action.

## Auto-Tidy

Enable Auto-Tidy in settings to run tab cleanup on a schedule. The agent will periodically organize tabs in the background.
