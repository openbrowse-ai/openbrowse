OpenBrowse fully supports OpenAI's latest models. GPT-5.5 and GPT-5-mini provide excellent reasoning and tool-calling capabilities, making them highly recommended for complex browser automation tasks.

## Setup

1. Go to **Settings → Models**.
2. Select **OpenAI**.
3. Enter your [OpenAI API key](https://platform.openai.com/api-keys).
4. Choose a default model, like `gpt-5.5`.

## Reasoning Models (o1/o3/o4)

OpenBrowse supports OpenAI's reasoning models. If you select a reasoning model, you can configure the "Reasoning Effort" (low, medium, high) directly from the model picker.
