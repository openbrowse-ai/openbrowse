OpenBrowse natively supports Anthropic's Claude models. Claude 4.6 Sonnet is currently one of the best-performing models for complex browser automation, tool usage, and code execution tasks.

## Setup

1. Go to **Settings → Models**.
2. Select **Anthropic**.
3. Enter your [Anthropic API key](https://console.anthropic.com/settings/keys).
4. Choose a default model, like `claude-sonnet-4-6`.

## Extended Thinking

OpenBrowse supports Anthropic's Extended Thinking capabilities on compatible models. 

When you select a compatible model, a "Thinking Budget" slider will appear in the model picker, allowing you to allocate up to 32K tokens for the model to "think" before responding.
