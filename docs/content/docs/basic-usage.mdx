## Keyboard shortcuts

OpenBrowse ships with three global shortcuts, one for each surface:

| Shortcut | Action |
| --- | --- |
| `⌥K` / `Alt+K` | Command palette — search tabs, switch spaces, run AI actions |
| `⌥I` / `Alt+I` | Agent side panel — longer conversations with the agent |
| `⌥⇧I` / `Alt+Shift+I` | OpenBrowse home tab — switches to it, or creates a pinned one |

You can rebind any of them in `chrome://extensions/shortcuts`.

## Command palette

Press `⌥K` to open the overlay on any tab. From here you can:

- Search open tabs
- Switch between spaces
- Run quick actions
- Chat with the AI agent

## Side panel

Press `⌥I` to open the agent side panel, or click the OpenBrowse icon in the Chrome toolbar. This is where you interact with the agent for longer conversations.

## Home tab

Press `⌥⇧I` to jump to the OpenBrowse home tab. If it doesn't exist yet, it's created as a pinned tab in the current window.

## Spaces

Spaces are window-based tab groups with color themes. Each Chrome window can be a separate space with its own visual identity.

## Picking a model

OpenBrowse works with any AI model — local or cloud. By default it uses
Chrome's built-in Gemini Nano (no setup, no key). To switch:

1. Open the side panel (`⌥I`)
2. Click the model picker at the bottom
3. Choose a built-in option, or add your own API key

See [Models & Providers](/docs/models-and-providers) for the full list.
